# Support Korako Yolawani

> **Help fund reliable, human-directed AI work — with evidence before claims.**

Korako Yolawani is an active prototype exploring a simple product promise:

```text
ONE HUMAN → ONE GOAL → ONE JOURNEY → VERIFIED DONE
```

The project is currently focused on **Mira**, the conversational front door, and on proving one complete end-to-end Journey repeatedly before expanding the surface area.

## Ways to support

### 1. Financial sponsorship

Financial support helps cover the real costs of building and validating Korako, including:

- model, API and compute usage where local/free capability is insufficient;
- voice and realtime infrastructure;
- cloud/runtime infrastructure;
- test devices and compatibility work;
- security, reliability and independent review;
- reproducible public evidence and pilot measurement.

A direct recurring/one-time payment channel will only be published here after the maintainer activates and verifies it. Until then, use the sponsorship inquiry below to discuss support.

### 2. Pilot partnership

A useful pilot partner brings a real multi-step workflow that can be measured honestly.

Good pilot candidates have:

- repeated coordination across tools, people or systems;
- clear success criteria;
- a meaningful Human Gate before consequential actions;
- measurable manual effort that can be compared with Korako-assisted work.

Korako does **not** claim quantified time savings until paired measurements exist.

### 3. Infrastructure sponsorship

Infrastructure partners can support the project with compute, model/API credits, hosting, test hardware, security review or other clearly bounded resources.

In-kind support is recorded separately from product evidence. A sponsorship does not turn a provider into Korako's source of authority.

### 4. Technical review

Independent reviewers are especially valuable for:

- reliability and recovery;
- security and permission boundaries;
- voice/session architecture;
- orchestration and verification;
- reproducibility of public proof.

Start with [Investor / Technical Diligence](docs/INVESTOR_DILIGENCE.md) and [Independent Reproduction](docs/INDEPENDENT_REPRODUCTION.md).

## Sponsorship levels

These levels describe recognition and collaboration, not access to a less-safe product.

| Level | Intended for | Recognition / involvement |
| --- | --- | --- |
| **Supporter** | Individuals who want to help the project continue | Name/handle in the public supporters section when requested |
| **Builder** | Small teams and companies | Logo/link placement in the sponsor page when agreed |
| **Founding Partner** | Organizations bringing a measurable pilot | Pilot collaboration, public credit where mutually approved |
| **Infrastructure Partner** | Compute, cloud, model, hardware or review providers | Infrastructure credit with the supported capability clearly identified |

Amounts and commercial terms are intentionally **not invented in advance**. They are agreed explicitly and published only when a real funding channel exists.

## What sponsorship does *not* buy

Sponsorship does not buy:

- bypasses around Human Gates;
- unverified completion claims;
- private user data;
- hidden influence over verification;
- a misleading public endorsement;
- access to credentials, private operational logs or security-sensitive implementation details.

The project keeps the same core boundary:

```text
PREPARED != EXECUTED != VERIFIED != PUBLICLY REPRODUCED
```

## Funding → milestone discipline

Support is meant to accelerate evidence, not replace it.

Current sequence:

```text
M1 Runtime Recovery
  → ONE MIRA
  → 10× consecutive verified voice passes
  → ONE VERIFIED JOURNEY
  → 10 real users
  → first payment
  → repeat usage / retention
  → second Journey
  → Founding 100
  → measurable revenue + Time Returned
  → M10 evidence
```

Milestones remain claims only when supported by evidence appropriate to that milestone.
